# 🌟 Oasis Infobyte Internship Projects (Data Science Domain)

This repository contains the completed tasks for the **Oasis Infobyte Internship**, focused on real-world Data Science and Machine Learning problems.

---

## 📁 Task List

### ✅ 1. **Iris Flower Classification**
- **Description**: A supervised classification problem to predict the species of an iris flower using features like petal length, petal width, etc.
- **Tech Stack**: Python, Scikit-learn, Pandas, Matplotlib, Seaborn
- **Highlights**: Logistic Regression, Decision Tree, and KNN models applied and compared.

### ✅ 2. **Unemployment in India**
- **Description**: Data analysis and visualization of unemployment trends in India.
- **Tech Stack**: Python, Pandas, Plotly, Seaborn
- **Highlights**: Heatmaps, bar charts, and time-series analysis of unemployment rate data.

### ✅ 3. **Car Price Prediction**
- **Description**: A regression model to predict the resale price of used cars based on various features.
- **Tech Stack**: Python, Scikit-learn, Pandas, Matplotlib
- **Highlights**: Linear Regression, Random Forest, feature engineering and model evaluation.

### ✅ 4. **Spam Detection**
- **Description**: A Natural Language Processing (NLP) project to classify emails or messages as spam or not spam.
- **Tech Stack**: Python, NLTK, Scikit-learn
- **Highlights**: Text vectorization, Naïve Bayes classifier, model evaluation using confusion matrix.

### ✅ 5. **Sales Prediction**
- **Description**: Predict future sales using historical sales data.
- **Tech Stack**: Python, Pandas, Matplotlib, Scikit-learn
- **Highlights**: Data preprocessing, exploratory data analysis (EDA), and regression model.
